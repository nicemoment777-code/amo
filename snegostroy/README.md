# Снегострой

Самостоятельное браузерное приложение для проектирования снежных крепостей. Интерфейс на русском. Координатная единица — 120 мм. Размеры геометрии совпадают с размерами деталей; швы нарисованы текстурой.

## Запуск

Нужен Node.js 20 или новее. Установка пакетов и сборка не требуются: Three.js, OrbitControls и шрифт включены в `dist`.

```powershell
node server.mjs
```

Открыть http://127.0.0.1:4187/snegostroy/ . Для собственного хостинга достаточно содержимого `dist` в отдельном каталоге. Канонический целевой адрес: https://snowbrick.ru/777/ .

## Управление

- В коллекции выберите образец, затем щёлкните по полю. R поворачивает устанавливаемый образец на 90°.
- Вкладка «Кирпичики»: целый 240 × 120 × 120 мм и половинка 120 × 120 × 120 мм. Наведение на грань показывает результат установки.
- В режиме «По кирпичикам» выберите деталь. Наведение на кнопку поворота показывает результат, щелчок применяет допустимый поворот. Неподходящее положение подсвечивается красным и не применяется.
- Shift + щелчок выбирает несколько деталей. Кнопка сохранения создаёт личный образец; его копии независимы.
- Камера: перетаскивание левой кнопкой, колесо, правая кнопка для сдвига. Во время установки Alt + левая кнопка вращает камеру. Есть отдельные кнопки обзора, сдвига, вида сверху и масштаба.
- Ctrl+Z / Ctrl+Shift+Z — отмена / повтор, Esc — отмена инструмента, Delete — удаление. «Чистое поле» также можно отменить.
- Проект, настройки и собственная коллекция хранятся только в localStorage этого браузера под ключом `snegostroy.project.v1`. Экспорт и импорт JSON позволяют перенести их на другое устройство.

## Проверки

`node --test tests/geometry.test.mjs` проверяет стык без зазора, перевязку, вертикальные кирпичики, OBB-пересечения при произвольном угле, геометрию коллекции, независимость копий и расчёт времени.

`qa-interactions.mjs` и `qa-editing.mjs` — выполненные проверки в браузере Edge через Playwright: ручная сборка, сохранение образца, копирование, вращение на 37°, отмена/повтор, сохранение после перезагрузки, импорт, расчёт, редактирование повёрнутой башни, запрет пересечения, вид сверху. В `qa` находятся снимки интерфейса и результаты.

## Изолированное размещение

`ops/deploy-isolated.sh` размещает только этот проект в `/var/www/snegostroy/releases/<SHA>`, переключает отдельную ссылку `current` и подключает маршрут `/777/` через `ops/snegostroy-777.conf`.

Код, база, переменные и служба AmaCRM не изменяются. Nginx получает один include перед прежним обработчиком остальных адресов и проходит `nginx -t` перед плавной перезагрузкой. Сохраняется резервная копия исходного конфигурационного файла. Сравниваются PID действующей службы и ответы её health/login до и после публикации.

Если другое приложение в будущем полностью перезапишет общий конфигурационный файл Nginx, включение `/etc/nginx/snippets/snegostroy-777.conf` понадобится сохранить. Сам конструктор при этом остаётся в отдельной директории.
