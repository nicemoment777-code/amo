# Личная интеграция Снегострой

Комплект предназначен только для аккаунта `snegostroy.amocrm.ru`, воронки `8604134`. В общем amoMarket не публикуется. Виджет открывает защищённую страницу подключения устройств; фоновую печать выполняет установленная программа Windows.

## Установка на другой компьютер

1. Установите обычный Windows-драйвер принтера. Поддерживается выбор принтера из списка Windows; подтверждённая модель — 4BARCODE 3B-T361U. Для этикетки 74 × 105 мм с добавленной полосой требуется итоговая длина 120 мм.
2. Перенесите `SnowbrickSetup.exe` на Windows 10/11 x64 и запустите. Установка выполняется в папку текущего пользователя, администратор не требуется. Python, Codex и PowerShell 7 не нужны.
3. Откройте «Снегострой → Печать СДЭК» из меню Пуск. Нажмите «Подключить компьютер».
4. Войдите на `https://snowbrick.ru/integrations/amocrm` и в разделе «Компьютеры печати» введите показанный приложением код. Разрешайте только запрос со своего компьютера. Код действует 10 минут.
5. Вернитесь в программу. Откройте «Настройки», выберите принтер Windows. В основной панели выберите период и нажмите «Показать». Для проверки можно явно напечатать одну выбранную карточку.
6. В настройках нажмите «Включить автопечать». При необходимости включите «Запускать при входе в Windows».

Программа должна работать, компьютер — оставаться включённым, принтер — подключённым. Закрытие программы останавливает её проверки. Автозапуск действует при входе в Windows, не до входа пользователя.

## Панель заказов

Главное окно показывает четыре карточки в ряд. Карточки группируются по одинаковому набору артикулов, большие группы идут первыми; внутри группы — ранние заявки первыми. Цвет зависит от артикула и остаётся одинаковым после перезапуска. Несколько артикулов одной заявки остаются в одной карточке и печатаются одной этикеткой. Прокрутка — колёсиком или полосой справа.

Номер заказа берётся из `ORDERID` заявки amoCRM (при отсутствии — из «Номер заказа»), ведущие нули сохраняются. ID сделки показан отдельно мелким текстом. Если номер заказа не заполнен, заголовок `amo …` явно показывает ID сделки вместо выдуманного номера. Артикулы берутся только из круглых скобок «Состава заказа» этой заявки. Пример из изображения владельца и тестовые данные в рабочую панель не загружаются.

## Принтеры и артикулы

В верхней панели выберите принтер Windows, откройте список «Выбрать артикулы», отметьте нужные артикулы из amoCRM и нажмите «Сохранить назначение». Для другого принтера повторите выбор. Один принтер может печатать несколько артикулов. Артикул, закреплённый за другим принтером, недоступен в списке: сначала снимите его с прежнего назначения и сохраните изменения. Полностью убрать принтер из списка можно кнопкой «Снять назначение».

Настройки действуют на этом компьютере для автоматической и ручной печати, хранятся отдельно от истории в `printing/printer-routes.json`. До первого назначения сохраняется прежний принтер по умолчанию. После включения назначений нераспределённые артикулы не печатаются. Удаление последнего назначения тоже оставляет заявки ждать настройки, не переключает их на произвольный принтер.

Если в одной заявке несколько артикулов, все они должны быть закреплены за одним принтером. При разных назначениях этикетка не печатается и не дублируется; программа сообщает о конфликте. Формат этикетки и проверка штрихкодов сохраняются.

Сверху выбираются начало и конец периода поступления: дата через календарь или `ДД.ММ.ГГГГ`, время `ЧЧ:ММ`, часовой пояс Москва. Есть быстрые кнопки «Сегодня» и «Последние 2 часа». Просмотр старых заявок не меняет время включения агента и не добавляет их в автоматическую очередь. Список обновляется каждые пять минут и кнопкой «Обновить».

Зелёная галочка означает сохранённое на этом компьютере подтверждение передачи драйверу. Она не доказывает физический выход бумаги. Красный восклицательный знак означает отсутствие подтверждения, неопределённую попытку или отсутствие данных о печати на другом компьютере. Серверное резервирование само по себе не считается успешной печатью. При отсутствии этикетки или артикула кнопка недоступна.

Кнопка «Повторная печать» / «Напечатать этикетку» относится только к выбранной заявке. После подтверждения номера и принтера отправляется один экземпляр в утверждённом формате, с повторной проверкой исходных штрихкодов. Перед передачей драйверу сохраняется неопределённое состояние; при ошибке автоматического повтора нет. История прочих заказов и дата начала работы сохраняются.

На исходном компьютере панель может использовать существующие ключ и историю агента: `pwsh -NoProfile -File ops/open-print-panel.ps1`. Этот запуск не включает ещё один автоматический цикл. Для другого компьютера используется установщик и отдельное подключение устройства, описанные выше. В установщик история и ключ исходного компьютера не включаются.

## Виджет amoCRM

В amoMarket откройте созданную личную интеграцию и загрузите архив `snowbrick-amocrm-widget.zip` как архив виджета. Устанавливайте только в собственный аккаунт; отправка на публичную модерацию не требуется для личного использования. Ключи в архив не входят.

Виджет показывает справочную панель в карточке сделки и ссылку на подключение компьютеров. Выбор принтера, запуск, остановка и локальный журнал находятся в программе Windows. Виджет не хранит ключи и не запускает печать из браузера.

Если загрузка архива отклонена amoCRM, сохраните сообщение ошибки для проверки. Установка виджета в реальном аккаунте проверяется отдельно от сборки ZIP; не считать сам факт сборки успешной установкой в amoCRM.

## Формат и порядок

Сохраняется исходная этикетка 1:1. Сверху добавляется полоса 15 мм с областью 70 × 15 мм. Печатаются только артикулы из круглых скобок. Перед отправкой проверяются штрихкоды. Каждые пять минут готовые этикетки группируются по одинаковому набору артикулов, группы идут по убыванию числа заявок. Одна заявка — один экземпляр. Старые заявки до первого запуска нового компьютера не печатаются; для переноса ожидающих старых заданий нужен отдельный перенос истории, её нельзя сбрасывать.

## Устройства и защита от дублей

Каждый компьютер имеет отдельный ключ, зашифрованный Windows DPAPI в `%LOCALAPPDATA%\SnowbrickPrinter\device-key.bin`. В установщике нет секретов, токенов и заказов. Ключи amoCRM остаются на сервере. Отозвать доступ можно в разделе устройств на сайте.

Дополнительно к локальному журналу сервер атомарно резервирует заявку перед печатью. Второй компьютер не сможет повторить это задание. Если сбой произошёл после резервирования, повторная печать автоматически не разрешается: сначала проверьте физический отпечаток и очередь Windows. Не удаляйте локальную или серверную историю для повторения задания.

Пользовательские настройки и PDF находятся в `%LOCALAPPDATA%\SnowbrickPrinter`, программа — в `%LOCALAPPDATA%\Programs\SnowbrickPrinter`. Эти папки могут содержать персональные данные. Не отправлять их в публичные репозитории или логи.

Для удаления отключите автозапуск, закройте программу, удалите папку программы и ярлык меню Пуск. При передаче компьютера другому человеку сначала отзовите устройство на сайте. Удаление самой программы не удаляет историю и ключ автоматически.

## Сборка

`desktop/build.py` использует локальный bundled Python, PyInstaller из `data/build-tools`, zxing-cpp из `data/printing/vendor`, runtime Poppler. Исходники программы — `desktop/app.py`, установщика — `desktop/Setup.cs`, виджета — `widget/`. Артефакты находятся в игнорируемом `dist/`. Сборка явно включает только программные файлы и библиотеки; `data/`, `.env`, настройки и документы заказов в неё не входят.
