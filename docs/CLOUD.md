# Работа из браузера

## Codex Cloud

1. Откройте Codex в ChatGPT и подключите репозиторий `nicemoment777-code/amo`.
2. Выберите ветку `main`, создайте среду репозитория и укажите Node.js 24.
3. Для подготовки достаточно команды `node --test`: проект не требует установки npm-пакетов. Для изменения интерфейса и тестов живые ключи не нужны.
4. Начните задачу с просьбы прочитать `AGENTS.md` и `docs/HANDOFF.md`. Например: «Продолжи подготовку размещения приложения на VPS по docs/DEPLOYMENT.md; сначала проверь доступность SSH. Не публикуй данные заказов и секреты».
5. Изменения просматривайте в diff/PR, затем переносите в `main`.

Среда Codex создаётся для задач разработки. Постоянная работа приложения, хранение заказов и приём вебхуков должны происходить на VPS.

## Секреты и сеть

GitHub Actions Secrets не импортируются в Codex автоматически. Если setup script требует ключей, их задают отдельно в настройках Secrets среды Codex. Согласно [официальной документации](https://learn.chatgpt.com/docs/environments/cloud-environment), такие секреты доступны setup script и удаляются из окружения до работы агента. Не переносите их в `.bashrc` или файлы репозитория, чтобы обходить это ограничение.

Для дальнейших операций с сервером можно разработать отдельный GitHub Actions workflow с ручным запуском и минимальными правами: он получает необходимые repository secrets непосредственно во время выполнения. В этом репозитории пока добавлена только проверка тестов; автоматическое развёртывание не настроено, поскольку SSH и отпечаток ключа сервера ещё не проверены.

В Codex интернет во время работы агента по умолчанию выключен и настраивается отдельно; трафик среды проходит через HTTP/HTTPS-прокси. Поэтому переезд в облако сам по себе не гарантирует прямой SSH-доступ к VPS. Сначала проверить сеть и SSH отдельно, затем выбирать способ развёртывания. [Документация сред Codex](https://learn.chatgpt.com/docs/environments/cloud-environment).

## GitHub Actions

Workflow `Tests` запускает `node --test` на push/PR; его также можно запустить вручную во вкладке Actions. Он не получает пароли, не обращается к живому СДЭК и не публикует данные заказов.
