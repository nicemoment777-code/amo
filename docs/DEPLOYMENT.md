## SSH

```bash
ssh -o StrictHostKeyChecking=yes root@194.58.102.218
```

Эта команда рассчитана на уже сохранённый ключ сервера. На новом компьютере сначала добавьте доверенную строку из `VPS_SSH_KNOWN_HOSTS` в файл `~/.ssh/known_hosts`. Пароль вводится в приглашении SSH и хранится в `VPS_SSH_PASSWORD`.

Зафиксированный отпечаток ED25519:

```text
SHA256:CcpNtAbdlRzJiL6Bj7QXXCTCRM/8YTV2kuiYhYWjYxU
```

Ключ получен при первом подключении и совпал с ключом из авторизованной сессии. В Actions используется сохранённая строка known_hosts; повторное получение произвольного ключа из сети при каждом запуске не требуется. Для независимой проверки сравните отпечаток через консоль провайдера.

Обе записи проверены 17.09.2026 в 21:10–21:11 МСК через DNS-over-HTTPS Google и Cloudflare: новый IP получен для обоих имён. Google вернул TTL 21600 секунд, Cloudflare — 86400 секунд. Запрос AAAA для основного домена через Google не вернул IPv6-адреса. Обычные локальные DNS-запросы в тот же момент показывали старый IP `194.58.112.174` с TTL 86400; это расхождение не отменяет внешнюю проверку, но означает, что не все пути разрешения имён уже показывают новое значение.

Для workflow в GitHub Secrets сохранено `REG_VPS_DOMAIN=snowbrick.ru`. Основной URL — https://snowbrick.ru/. `www.snowbrick.ru` покрыт сертификатом и перенаправляет на основной домен.

## Развёртывание

В репозитории есть `ops/provision-server.sh` и ручной workflow `Deploy production`. Они обновлены для страницы входа и успешно применены на новом VPS. Workflow останавливается, если домен не указан или его IPv4-адрес отличается от целевого VPS. Параллельные развёртывания исключены настройкой concurrency.

Сценарий устанавливает Node.js, Nginx и HTTPS, создаёт службу `amo.service`, хранит данные в `/var/lib/amo` и переменные в `/etc/amo.env`. Node.js остаётся на `127.0.0.1:3080`; внешний доступ к панели защищается серверной сессией после входа на `/login`, webhook имеет отдельный секретный путь без access log. Порт 3080 наружу не открывать.

Старый сервер и его webhook не удалены. Через API подтверждены две подписки `ORDER_STATUS`: прежняя Cloud4box и новая `snowbrick.ru`. Не создавать дополнительные подписки бесконтрольно. HTTPS, вход, выход, 20 API-заказов и 20 сохранённых снимков кабинета проверены; получение нового реального события СДЭК ещё предстоит подтвердить.

Команды проверки на сервере:

```bash
systemctl is-active amo.service nginx.service
systemctl is-enabled amo.service
curl --fail --silent http://127.0.0.1:3080/healthz -o /dev/null
```

Страница входа, хранение пароля и проверки авторизации описаны в [AUTH.md](AUTH.md). Сертификат покрывает основной домен и `www`, срок до 16.12.2026; `certbot.timer` активен.

Ответы с заказами не выводить в публичные журналы. Сведения о предыдущем сервере сохранены в [LEGACY-CLOUD4BOX.md](LEGACY-CLOUD4BOX.md).
