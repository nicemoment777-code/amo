# Передача проекта — 17 сентября 2026

## Что готово

Репозиторий: https://github.com/nicemoment777-code/amo, основная ветка `main`.

Веб-приложение на Node.js без внешних npm-зависимостей развёрнуто на VPS Cloud4box `185.77.219.91` (`861659.cloud4box.ru`). Сервер подтверждён как Ubuntu 26.04 LTS. Приложение работает локально на `127.0.0.1:3080` как включённая служба systemd `amo.service`; наружу опубликовано через Nginx.

Публичный адрес панели: `https://861659.cloud4box.ru/`. HTTPS настроен через Let's Encrypt, автоматическое продление сертификата включено. Сертификат, выпущенный при развёртывании 17.09.2026, действует до 16.12.2026. Интерфейс и `/api/*` защищены HTTP Basic Auth. Имя пользователя панели — `admin`; сгенерированный пароль хранится только на VPS в `/root/amo-dashboard-credentials.txt` с доступом root и не публикуется в GitHub Actions или репозитории.

Приложение хранит рабочие данные в `/var/lib/amo`, секреты СДЭК — в `/etc/amo.env` с ограниченными правами. Релизы размещаются в `/opt/amo/releases/`, текущий релиз подключён через `/opt/amo/current`. Код приложения не слушает внешний интерфейс: порт 3080 остаётся loopback-only.

Во время production preflight подтверждены SSH-доступ к VPS и рабочая авторизация в API СДЭК. Все 20 известных номеров из `CDEK_ORDER_NUMBERS` доступны через API. После развёртывания все 20 заказов загружены на VPS, ошибок первичной синхронизации — 0. Известные номера обновляются при запуске и каждые 15 минут; очередь сохраняется, ошибки повторяются раз в минуту.

Публичный приёмник `POST /webhooks/cdek/<секрет>` опубликован через HTTPS отдельно от панели; access log для этого location отключён. Случайный `CDEK_WEBHOOK_SECRET` создан на VPS. В СДЭК зарегистрирована подписка `ORDER_STATUS`; существующие посторонние подписки не удалялись. Новые номера из webhook ставятся в очередь, после чего полная карточка перечитывается через авторизованный API СДЭК.

## Ограничение исторического архива СДЭК

API СДЭК позволяет получать заказ по известному UUID или номеру накладной, но не предоставляет общего метода перечисления всех исторических заказов аккаунта. Поэтому сейчас на сервере есть все 20 известных накладных из `CDEK_ORDER_NUMBERS`, а будущие неизвестные номера будут обнаруживаться через `ORDER_STATUS` webhook. Чтобы добавить более старые заказы, которых нет в этой выборке, нужен дополнительный список их номеров из личного кабинета СДЭК.
