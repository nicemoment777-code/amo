Подключите свой компьютер печати

Установите обновлённый модуль Windows, подтвердите компьютер в разделе подключения. Затем выберите его здесь. Просмотр заявок и общей истории работает на сервере. Для печати сайт подключается к вашим принтерам через модуль Windows.

Данные amoCRM остаются в подключённом аккаунте. Для печати компьютер должен быть включён. Модуль запускается при входе в Windows и продолжает работать после закрытия окна; Codex не требуется.

Один артикул закрепляется только за одним принтером. Настройки относятся к выбранному компьютеру.

Принтер доставки имеет приоритет над артикулами. Один принтер можно выбрать для обеих доставок. «По артикулам» использует строки ниже.
