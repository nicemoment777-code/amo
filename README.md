Репозиторий публичный. Значения ключей и паролей хранятся в GitHub Actions Secrets. Файлы `.env`, база заказов и SSH-ключи в Git не входят.

Локальное веб-приложение: массовая загрузка накладных из API СДЭК, поиск, фильтры, история статусов, получатели, товары и полный ответ API. Никаких демонстрационных заказов.

## Запуск

Нужен Node.js 22.9+ (проверено на 24). Скопируйте `.env.example` в `.env`, укажите рабочие `CDEK_CLIENT_ID` и `CDEK_CLIENT_SECRET`, затем:

```sh
node --env-file-if-exists=.env server.mjs
```

Откройте http://127.0.0.1:3080. Сервер доступен только на этом компьютере. Зависимости устанавливать не требуется. Альтернативные имена переменных: AMO_ACCOUNT_ID / AMO_PASSWORD (существующие секреты GitHub). GitHub Secrets не передаются локальному приложению автоматически.

## Полная история

В официальном API https://apidoc.cdek.ru/ получение заказа требует UUID или номера накладной. Общего метода перечисления всех заказов нет. Для первой загрузки нужен полный список номеров из личного кабинета СДЭК; вставьте его в приложение. API ограничивает доступность заказов из других каналов датой первой авторизации интеграции. Поэтому наличие ключей не гарантирует получение всей исторической базы.

Известные накладные обновляются через API при запуске и каждые 15 минут, пока приложение работает. Интервал задаёт `SYNC_INTERVAL_MINUTES`. Кнопка «Обновить» запускает тот же процесс вручную. Очередь сохраняется в `data/queue.json`; неудачные запросы повторяются раз в минуту. Ранее импортированная карточка сохраняется как `cabinetSnapshot`, актуальные поля берутся из API. Даты в фильтрах относятся к последнему статусу. Экспорт JSON сохраняет все поля выбранных заказов.

Новые неизвестные номера пока добавляются импортом. Приёмник `POST /webhooks/cdek/<секрет>` реализован, но публичный адрес и подписка СДЭК не настроены. Чтобы подключить его позже: задать случайный `CDEK_WEBHOOK_SECRET` длиной минимум 32 символа, открыть через HTTPS reverse proxy только этот путь, проверить доступность и зарегистрировать подписку `ORDER_STATUS` в `POST https://api.cdek.ru/v2/webhooks`. Сначала проверить существующие подписки; не удалять чужие. Сам интерфейс и `/api/*` оставлять локальными, пока не добавлена аутентификация. Секретный путь не логировать. Полученные номера ставятся в очередь, а содержимое заказа заново читается через авторизованный API; данные вебхука не заменяют карточку напрямую. Вебхуки не восстанавливают старый архив.

В Windows запустите `start.ps1` из PowerShell. Закрытие процесса, выключение или сон компьютера останавливают обновления. Автозагрузка Windows не настроена.

## Хранение

Ключи находятся в `.env`, токен — только в памяти сервера. Заказы записываются в `data/orders.json` с атомарной заменой файла. `.env` и `data/` исключены из Git. Не публикуйте их в репозитории. Это локальное приложение; для размещения на сервере требуется добавить вход пользователей и HTTPS.
